# 90-Day Growth Plan

**Beachhead:** Bangla-speaking IELTS candidates (Bangladesh + diaspora). Expand only when retention, outcomes, willingness-to-pay and unit economics support it — in that order. No outreach campaigns, no advertising, no invented social proof at any point.

## Days 1–30 — Prove the habit (pilot, 30–50 learners)

- Run the pilot exactly per `PILOT.md`; gates G1–G3 enforced.
- Distribution is partner-led: coaching-centre partners introduce the tool to their own students (referral + partnership mechanics shipped at `/refer`, `/partners`).
- Weekly honest metrics email to partners: activity, retention windows, incidents. No vanity metrics.
- Support loop: teacher review queue < 48h; learner questions < 24h weekdays.
- **Exit criteria:** G1 + G3 pass, zero P1 incidents for 2 consecutive weeks.

## Days 31–60 — Prove the economics (still beachhead)

- Live billing integration for Bangladesh (bKash/Nagad via SSLCommerz or equivalent) — explicit release step with its own checklist; sandbox remains the default until then.
- Open paid conversion to week-1-retained pilot learners only; measure H5/H6 with real money, not intent.
- Referral programme goes live with automated crediting (replaces manual pilot process; page copy updated in the same commit).
- Second teacher cohort onboarded (Teacher-Supported plan) → measure H7 at small scale.
- **Exit criteria:** ≥ 10 paying learners at ৳1,150, AI cost ≤ 35% of revenue per active learner, cancellation < 20%/month, refund handling verified with real provider webhooks.

## Days 61–90 — Decide expansion (evidence-gated)

Only if days 31–60 exits are met, in priority order:
1. **Depth in beachhead:** more mock library content (rights-cleared), Bangla UI coverage expansion, exam-date-aware study plans.
2. **Adjacent segment:** Bangla-speaking TOEFL candidates (product already ships TOEFL paths — validate with 10–15 learners before marketing a word).
3. **Coaching-centre scale:** self-serve teacher seats once H7 holds across ≥ 3 centres.

Deferred until evidence exists: other L1 segments (Hindi/Urdu/Arabic), general-English mass market, mobile native apps, any paid acquisition.

## Non-negotiables

- Every public claim traces to a shipped feature or a measured metric.
- Retention/outcome data reported with denominators and windows, never cherry-picked.
- Growth never outruns support capacity: cap signups when the review queue exceeds 48h coverage.
